# Submission Checklist

Use this checklist after completing the real Git/GitHub steps. Do not mark steps complete until you have done them.

- [ ] Confirm `git --version` works.
- [ ] Configure your name and email with `git config --global user.name` and `git config --global user.email`.
- [ ] Initialize the repository and check `git status`.
- [ ] Make at least three meaningful commits and confirm them with `git log --oneline`.
- [ ] Create a GitHub repository and connect it as `origin`.
- [ ] Push `main`, make another commit, and push again.
- [ ] Create and push a feature branch.
- [ ] Open a pull request, review it, and merge it on GitHub.
- [ ] Capture genuine screenshots of terminal output, repository, commit history, branch, and merged pull request.
- [ ] Replace the student name placeholder in README.
- [ ] Put your actual repository and pull request URLs in your final submission document.

## Suggested evidence captions
1. Git version and configuration
2. Repository initialized and working tree status
3. Three commits shown in `git log --oneline`
4. GitHub repository and first push
5. Feature branch and pull request
6. Merged pull request and final repository history
